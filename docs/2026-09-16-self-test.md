## Reproduce discovery without changing a profile

```sh
npm run evidence:replay -- /private/path/input.json /private/path/run-2026-09-16.json
```

Requires Node 22+ with native type stripping. Input contains `capturedAt` and
`entries`. Each entry has `id`, `acquisition` (`PROVIDER`, `MANIFEST`,
`ASSISTANT_EXTRACTED`, or `USER_SUPPLIED`), `sourceRef`, the exact `excerpt`,
and a `signal` accepted by `rawSignalSchema`.

The replay calls the application's actual resolver and draft preparation.
It records the source commit, resolver hash, input hash, source references,
proposals, and unresolved evidence IDs. Outputs are create-only, mode 0600,
and must be outside the repository. It never writes to Convex or publishes.
Email extraction supplied by an assistant is explicitly labeled; the resolver
does not parse arbitrary receipt bodies or infer the owner's opinion.

Raw personal evidence, original outputs, and owner corrections belong in a
private evidence folder, never a Git commit. Preserve before/after runs using
the identical input, and record supplemental evidence separately.
